# Bishops' Co-Ed School, Undri — product render reference library

Every product family has two subfolders:

- `reference/` — the original supplied inspiration/reference images, renamed descriptively.
- `renders/` — a single `01-three-view-render.png` sheet: front, three-quarter, and reverse/detail views on pure white, with no cast shadows.

## Classification

1. `01-keychains` — denim star keyrings and strap keychains
2. `02-denim-diaries` — denim-covered diaries
3. `03-denim-pouches` — denim envelope and slim pouches
4. `04-bookmarks` — zodiac constellation and tarot-style bookmarks
5. `05-circle-badges` — circular pin badges
6. `06-zodiac-bandanas` — square zodiac-print bandanas
7. `07-zodiac-charms-and-bracelets` — zodiac phone charms and letter-bead bracelets
8. `08-zodiac-spin-wheel` — tabletop zodiac spin wheel
9. `09-zodiac-dice` — dice-and-dish game piece

The render sheets are visual reference assets, not manufacturing drawings. They deliberately preserve the supplied materials and motifs and avoid adding brands, slogans, or unrelated concepts.
