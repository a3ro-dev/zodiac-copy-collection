# Zodiac bookmarks — diffusion set

Five original illustrated bookmark fronts based on the supplied celestial and tarot bookmark references. The set includes Aries, Cancer, Leo, Scorpio, and Pisces.

## Files

- `diffusion/*-front-print.pdf` — individual press PDFs.
- `diffusion/*-front-bleed-300dpi.png` — 300 dpi print PNGs.
- `diffusion/source-art/` — original generated artwork before typesetting.
- `diffusion-bookmarks-images.zip` — all ten PNG images together: five print-ready fronts and five source art images.
- `diffusion/contact-sheet.jpg` — visual overview.
- `PROMPTS.md` — prompt summaries.
- `build_diffusion.py` — reproducible crop and typesetting script.

## Print size

PDF page size is 56 × 156 mm including 3 mm bleed on each side. The TrimBox is 50 × 150 mm and the BleedBox is the full page. PNG fronts are 661 × 1843 pixels at 300 dpi. Files use RGB; confirm the printer's CMYK profile and review a physical proof before a production run.
